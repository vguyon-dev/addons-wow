## 2. Spécialisations
- Armes (Arms) : dégâts, deux mains, gros coups. Nouveau : Spearing Strike, Victory Rush ; Slam sans interrompre le swing ; Improved Overpower, Bloodthrill.
- Fureur (Fury) : dégâts, deux armes. Peu changé hormis la génération de rage ; Whirlwind, Death Wish, Bloodthirst.
- Protection : tank, une main + bouclier. Charge et Thunder Clap utilisables en posture défensive ; Vanguard ; Victory Rush nouveau.
- Général : critique et toucher pour tous les types ; Expertise remplace les bonus de compétence ; rage normalisée par vitesse d'arme, très faible vs Classic ; la rage retombe hors combat ; plaque à niv. 40 ; Stoneform = 10 % de réduction physique.

## 3. Spé conseillée
- Solo (montée) : Method : Protection une main (solo/grind). Tavern : les trois sont possibles, Armes traditionnel ; RankedBoost : Armes. **Divergence.** Choix : Armes en montée si l'on veut tuer vite, Protection pour grosses packs. Le Guerrier est faible en solo (classé dernier RankedBoost).
- Groupe/donjon : Armes deux mains en groupe (Method) ; Protection comme tank.
- Raid : non publié. Repli Classic : Fureur dégâts, Protection tank.
- Groupe qui manque de tank : Protection. Qui manque de soigneur : le Guerrier n'a pas de rôle de remplacement ; groupe avec un soigneur « fortement recommandé » (Tavern).

## 6. À savoir
Solo :
- Les armes font 95-100 % des dégâts : mettre à jour l'arme est la priorité (Method).
- Garder de la rage pour le mob suivant, ne pas tout dépenser en Execute ; Premiers soins pour récupérer.
- Utiliser Intimidating Shout, Retaliation, Shield Wall plus librement pour tirer de grosses packs.
Groupe :
- Sunder Armor, Thunder Clap, Demoralizing Shout en entretien ; Battle Shout bénéficie au groupe.
- Les donjons offrent les améliorations d'armes ; grouper avec un soigneur.
- Rage très faible vs Classic : pooler la rage, ne pas la gaspiller sur des ennemis presque morts.
