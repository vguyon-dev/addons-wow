ADDONS DE VALENTIN : INSTALLATION
=================================

LE PLUS SIMPLE : WOWUP (mises à jour automatiques)
  1. Installe WowUp (https://wowup.io, gratuit) et laisse-le trouver WoW.
     En haut, choisis WoW Forever ou Retail.
  2. « Get Addons » > « Install from URL », colle
     https://github.com/vguyon-dev/addons-wow puis « Install ».
  3. C'est tout : WowUp te proposera chaque correction. Ensuite, va
     directement à « DANS LE JEU » plus bas.

SINON, À LA MAIN :

1. Ferme World of Warcraft.

2. Ouvre le dossier du jeu. Le plus simple : dans l'application Battle.net,
   choisis le jeu (WoW Forever ou Retail), clique sur la roue dentée à côté
   de « Jouer », puis « Afficher dans l'explorateur ».

3. Va dans le bon dossier :
     - WoW Forever : _forever_\Interface\AddOns
     - Retail      : _retail_\Interface\AddOns
   (si « Interface » ou « AddOns » n'existe pas, crée-le avec ce nom exact)

4. Copie dedans les dossiers du zip : CarnetDeSession, QuetesAuto,
   MarchandAuto, MetiersAuto, ButinRapide, QuetesDuGroupe, RapportErreurs, SacsRanges, AlerteRare, LivresBiblio (Forever seulement). Copie les DOSSIERS eux-mêmes,
   pas seulement ce qu'il y a dedans.
   Pour une mise à jour : remplace les anciens dossiers (tes réglages sont
   gardés, ils sont ailleurs).

5. Lance le jeu. Sur l'écran des personnages, bouton « AddOns » en bas à
   gauche : ils sont rangés ensemble dans la catégorie « Addons de Valentin ».
   Vérifie qu'ils sont cochés. Pour éviter les doublons, décoche
   AutoQuests et SpeedyAutoLoot si tu les as.

DANS LE JEU
-----------
Une seule icône (un engrenage) autour de la minimap pour tous les addons :
  clic = la liste des addons ; dans la liste, clic gauche = réglages,
  clic droit = activer ou couper. Glisser l'icône = la déplacer.

  /bv      Barres de vie (couleur selon la menace, rares et élites, pourcentage)
  /carnet  Carnet de session (temps, or, XP, monstres)
  /hv      Enchères (relevé des prix, liste de courses ; /hv releve à l'hôtel des ventes)
  /confort Confort (invocations, résurrections, invitations, duels, écran)
  /familier Familier du chasseur (faim, mort, oubli : bouton Nourrir, Ressusciter, Appeler)
  /montures Montures (une touche pour la bonne monture)
  /courrier Courrier (récupérer tout le courrier, l'or seulement ou les cochés)
  /fen     Fenêtres déplaçables (glisser la barre de titre d'une fenêtre du jeu ; /fen reset remet tout ;
           /fen second : le jeu sur un écran, les fenêtres sur l'autre, avec outilssecond-ecran.ps1)
  /qd      Quêtes disponibles (les « ! » des quêtes à prendre sur la carte ; /qd etat dit ce qu'il voit ; Forever seulement)
  /dial    Dialogues de quête (bandeau en bas à la place de la fenêtre du jeu ; /dial jeu la rend)
  /tenue   Tenues (fenêtre des tenues ; /tenue <nom> la met, /tenue retour remet la précédente)
  /sq      Suivi des quêtes (panneau rangé par genre ; /sq genre pour voir ce que dit le jeu)
  /way     GPS (/way 45.2 67.8 Titre, ou Ctrl + clic droit sur la carte ; /gps pour les réglages)
  /qa      Quêtes auto (rend puis accepte, partage en groupe)
  /ma      Marchand auto (vend les gris, répare, rachète ton stock)
  /livres  Livres de bibliothèque (Forever) : panneau, /livres proche pour une balise
           Désactive l'addon « Library Books » de Taraezor pour ne pas avoir deux fois les épingles
  /ar      Alerte rare et coffres (coupée au départ : /ar on pour l'activer)
  /sr      Sacs rangés (ranger les sacs ; équipement en double, moins bon ou que tu ne peux pas porter)
  /mt      Métiers auto (pêche au double clic droit, récolte, flèche vers les filons, liste de courses)
           Astuce : récolte sur la molette (bouton « Choisir la touche », puis roule la molette)
  /br      Butin rapide (ramassage rapide, sacs pleins, bilan de farm)
  /qg      Quêtes du groupe (en groupe : les quêtes de chacun ; ancien nom EntreFreres,
           supprime son vieux dossier si tu l'avais copié à la main)
  /re      Rapport d'erreurs : tes erreurs partent toutes seules à Valentin quand il est
           en ligne (groupe, guilde ou amis). /re test pour essayer, /re etat si rien n'arrive
           (les mêmes boutons sont dans la fenêtre de réglages).

En cas d'erreur : installe BugSack et BugGrabber (CurseForge) et envoie à
Valentin le message d'erreur.
